# 07-构建与启动规范

## 一、Maven配置
- ✅ JDK版本：25（启用--enable-preview）
- ✅ 父POM管理所有依赖版本
- ✅ 使用spring-boot-maven-plugin打包可执行Jar
- ✅ 编译参数必须包含 `--enable-preview`

## 二、注解处理器
必须配置以下注解处理器：
- lombok
- mapstruct-processor
- mybatis-flex-processor

## 三、配置文件规范
### 3.1 命名规范
| 环境 | 配置文件 |
|------|----------|
| 公共配置 | application.yml |
| 本地开发 | application-local.yml |
| 测试环境 | application-test.yml |
| 生产环境 | application-prod.yml |

### 3.2 配置优先级
1. 命令行参数
2. 环境变量
3. 外部配置文件
4. application-{profile}.yml
5. application.yml

### 3.3 敏感配置
- ❌ 敏感配置（数据库密码、密钥等）不应硬编码
- ✅ 使用Nacos配置中心管理敏感配置
- ✅ 使用环境变量注入敏感配置

## 四、打包规范
- ✅ 打包命令：`mvn clean package -DskipTests`
- ✅ 使用spring-boot-maven-plugin打包
- ✅ 打包后的Jar包含所有依赖（fat jar）
- ✅ 可直接运行：`java -jar xxx-starter.jar`
- ✅ 多模块打包顺序：shared → 业务服务 → gateway

## 五、运行规范
### 5.1 本地运行
```bash
cd xxx-service/xxx-starter
mvn spring-boot:run
```

### 5.2 生产运行
```bash
java -jar xxx-starter.jar --spring.profiles.active=prod
```

### 5.3 JVM参数
```bash
java -Xms512m -Xmx1024m -XX:+UseG1GC -jar xxx-starter.jar
```

## 六、启动顺序
1. Nacos服务注册中心
2. demo-gateway（API网关）
3. business-core-kernel（核心服务）
4. customer-service（客户服务）
5. file-service（文件服务）
6. integration-service（集成服务）
