# 08-错误码规范

## 一、错误码格式

错误码为**层级字符串**，格式：`<域>.<模块>.<序号>`

| 层段 | 含义 | 说明 |
|------|------|------|
| 域 | 错误域类别 | COMMON / SHARED / CORE / SERVICE |
| 模块 | 模块缩写 | 见下方码段分配表，大写字母 |
| 序号 | 模块内序号 | 0001-9999，模块内自增 |

**示例**：
- `COMMON.0000` — 操作成功
- `COMMON.0001` — 请求参数错误
- `SHARED.CRYPTO.0001` — 加密失败
- `SERVICE.FILE.0011` — 文件元数据不存在

## 二、域定义

| 域 | 含义 | 适用范围 |
|----|------|----------|
| COMMON | 通用 | 跨模块通用错误（HTTP 映射、成功码） |
| SHARED | 公共基础 | demo-shared 下的所有 shared-* 模块 |
| CORE | 业务核心 | business-core-kernel 下的模块 |
| SERVICE | 业务服务 | 各业务微服务（approval/file/integration/annuity） |

## 四、消息规范

- ✅ 消息内容使用纯文本，**禁止使用 `{}` 占位符**
- ✅ 消息应描述错误本质，便于用户理解
- ✅ 动态上下文通过 `BaseException.withUserDetail()` / `withLogDetail()` / `withContext()` 附加
- ❌ 禁止在消息中嵌入变量占位符（如 `"用户{}不存在"`）
- ❌ 禁止在消息中使用方括号前缀（如 `"[实体不存在]{}"`）

**正确示例**：
```java
ENTITY_NOT_FOUND("SHARED.DOMAIN.0001", "实体不存在"),
INVALID_DATA("SHARED.DOMAIN.0002", "数据校验失败"),
```

**错误示例**：
```java
ENTITY_NOT_FOUND("SHARED.DOMAIN.0001", "[实体不存在]{}"),  // 禁止方括号前缀和占位符
INVALID_DATA("SHARED.DOMAIN.0002", "[数据有误]{用户ID为空}"),  // 禁止嵌入变量
```

## 五、错误码唯一性

- ✅ 每个 code 值全局唯一，不允许跨枚举重复
- ✅ 同一枚举内各常量的 code 必须不同
- ❌ 禁止不同语义的错误共用同一 code
- ✅ 模块迁移时（如 lock 从 cache 拆出），错误码随之迁移，原模块不再定义该码

## 六、HTTP 状态码映射

HTTP 状态码由**异常类型**决定，而非错误码范围：

| 异常类型 | HTTP 状态 | 说明 |
|----------|-----------|------|
| `BusinessException` | 400（默认） | 业务异常，可通过 `@ResponseStatus` 覆盖 |
| `DomainException` | 400（默认） | 领域规则校验失败 |
| `SystemException` | 500 | 系统错误 |
| `CommonError.BAD_REQUEST` 等 | 对应 HTTP 4xx | 通用 HTTP 错误 |
| `CommonError.INTERNAL_SERVER_ERROR` 等 | 500 | 通用 HTTP 5xx |

> `GlobalExceptionHandler` 通过异常类型和 `@ResponseStatus` 注解决定 HTTP 状态，不解析错误码格式。

## 七、枚举命名规范

| 类型 | 命名模式 | 示例 |
|------|----------|------|
| 错误码枚举 | 模块名 + ErrorCode(s) | `SharedDomainErrorCode`、`FileErrorCodes`、`CryptoErrorCode` |
| 枚举常量 | 大写下划线 | `ENTITY_NOT_FOUND`、`ID_GEN_ERROR` |

## 八、使用约束

- ✅ 所有自定义异常必须携带 `ErrorDefinition`，禁止裸抛 `RuntimeException`
- ✅ 错误码定义在各自模块的 `errorcode` 包中
- ✅ 公共错误码（通用 HTTP 错误）定义在 `CommonError` 中
- ❌ 禁止在 domain 层抛出框架异常（如 Spring/MyBatis 异常），必须封装为 `DomainException`/`BusinessException`/`SystemException`
