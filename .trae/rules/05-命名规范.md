# 05-命名规范

## 一、模块命名
| 层级 | 命名模式 | 示例 |
|------|----------|------|
| 服务根模块 | xxx-service | customer-service |
| 领域原语层 | xxx-types | customer-types |
| 领域层 | xxx-domain | customer-domain |
| API层 | xxx-api | customer-api |
| 应用层 | xxx-application | customer-application |
| 适配器层 | xxx-adapter | customer-adapter |
| 基础设施层 | xxx-infrastructure | customer-infrastructure |
| 启动模块 | xxx-starter | customer-starter |

## 二、类命名
| 类型 | 命名模式 | 示例 |
|------|----------|------|
| 聚合根 | 业务名称 | BusinessApplication |
| 实体 | 业务名称 | OrderItem |
| 值对象 | 业务名称 | Money |
| 领域原语 | 业务名称 + No/Id | CustomerNo、ApplicationId |
| Repository接口 | 业务名称 + Repository | ApplicationRepository |
| Repository实现 | 业务名称 + RepositoryImpl | ApplicationRepositoryImpl |
| ApplicationService | 业务名称 + Service | CheckoutService |
| DomainService | 业务含义 + Service/Engine | MaterialRuleEngine |
| Command | 业务名称 + Command | CheckoutCommand |
| Query | 业务名称 + Query | OrderQuery |
| DTO | 业务名称 + DTO | OrderDTO |
| Exception | 业务名称 + Exception | BusinessException |
| Converter | 业务名称 + Converter | ApplicationConverter |
| Mapper | 业务名称 + Mapper | ApplicationMapper |
| DO | 业务名称 + DO | ApplicationDO |

## 三、方法命名
| 类型 | 命名模式 | 示例 |
|------|----------|------|
| 创建方法 | create | BusinessApplication.create() |
| 加载方法 | load | repository.load(id) |
| 加载或抛出 | loadOrThrow | repository.loadOrThrow(id) |
| 保存方法 | save | repository.save(entity) |
| 删除方法 | delete | repository.delete(entity) |
| 查询方法 | findByXxx | findByAcceptanceNo |
| 执行方法 | execute | engine.execute(context) |
| 验证方法 | validate | validator.validate(data) |
| 转换方法 | toXxx | converter.toEntity(do) |

## 四、字段命名
| 类型 | 命名模式 | 示例 |
|------|----------|------|
| ID字段 | xxxId | applicationId |
| 业务编号 | xxxNo | acceptanceNo |
| 状态字段 | xxxStatus | applicationStatus |
| 时间字段 | xxxTime | createTime、updateTime |
| 关联ID | xxxId | batchId |

## 五、包命名
| 层级 | 命名模式 | 示例 |
|------|----------|------|
| 根包 | com.example.xxx | com.example.customer |
| 聚合根 | .domain.aggregate.root | com.example.customer.domain.aggregate.root |
| 实体 | .domain.aggregate.entity | com.example.customer.domain.aggregate.entity |
| 值对象 | .domain.aggregate.valueobject | com.example.customer.domain.aggregate.valueobject |
| 领域事件 | .domain.event | com.example.customer.domain.event |
| Repository接口 | .domain.repository | com.example.customer.domain.repository |
| 领域服务 | .domain.service | com.example.customer.domain.service |
| 防腐层网关 | .domain.gateway | com.example.customer.domain.gateway |
| 错误码 | .domain.errorcode | com.example.customer.domain.errorcode |
| API接口 | .api | com.example.customer.api |
| DTO | .api.dto | com.example.customer.api.dto |
| Command | .api.command | com.example.customer.api.command |
| Query | .api.query | com.example.customer.api.query |
| 应用服务 | .application.service | com.example.customer.application.service |
| Controller | .adapter.controller | com.example.customer.adapter.controller |
| Adapter Converter | .adapter.converter | com.example.customer.adapter.converter |
| Repository实现 | .infrastructure.repository | com.example.customer.infrastructure.repository |
| DO实体 | .infrastructure.entity | com.example.customer.infrastructure.entity |
| Mapper | .infrastructure.mapper | com.example.customer.infrastructure.mapper |
| Entity Converter | .infrastructure.converter | com.example.customer.infrastructure.converter |
