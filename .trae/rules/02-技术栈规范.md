# 02-技术栈规范

## 一、核心框架
| 技术 | 版本 | 说明 |

| JDK | 25 | 启用--enable-preview |
| Spring Boot | 3.5.14 | 最新稳定版 |
| Spring Cloud | 2025.0.2 | 最新稳定版 |
| Spring Cloud Alibaba | 2025.0.0.0 | Nacos服务发现 |

## 二、数据访问
| 技术 | 版本 | 使用场景 |
|------|------|----------|
| MyBatis-Flex | 1.11.5 | ORM框架（唯一推荐） |
| PostgreSQL | - | 数据库首选（runtime依赖，file-service/integration-service 使用） |
| MySQL | - | 数据库备选（runtime依赖，approval-service 使用） |

> 各服务通过 schema-pg.sql / schema-mysql.sql 双套 DDL 保持兼容；新增服务默认选用 PostgreSQL。
